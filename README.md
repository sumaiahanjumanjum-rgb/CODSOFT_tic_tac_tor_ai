# 🎮 Tic-Tac-Toe AI

A simple Tic-Tac-Toe AI game built using Python.  
The player competes against the computer in a console-based game.

---

# 📌 Features

- Human vs AI gameplay
- Simple console interface
- Random AI moves
- Win, lose, and draw detection
- Beginner-friendly Python project

---

# 🛠️ Technologies Used

- Python 3

# ▶️ How to Run

## Step 1: Install Python

https://www.python.org/downloads/

Open terminal or command prompt inside the project folder.

```bash

```

# 🎮 Game Instructions

- You are **X**
- AI is **O**
- Enter numbers from **1 to 9** to place your move

Board Positions:

```text
1 | 2 | 3
--+---+--
4 | 5 | 6
--+---+--
7 | 8 | 9
```

---

# 🧠 AI Logic

The AI selects random empty positions on the board.
